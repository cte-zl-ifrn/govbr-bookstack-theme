# Labels de triagem

| Papel nas skills | Label no GitHub | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa de avaliação pelo mantenedor. |
| `needs-info` | `needs-info` | Aguarda informações adicionais. |
| `ready-for-agent` | `ready-for-agent` | Está especificada e pode ser executada por um agente. |
| `ready-for-human` | `ready-for-human` | Requer execução por uma pessoa. |
| `wontfix` | `wontfix` | O trabalho não será executado. |

Quando uma skill mencionar um papel de triagem, aplique o label correspondente desta tabela. Issues produzidas por `to-tickets` já estão especificadas e dispensam uma nova passagem por `triage`.
