# Instruções para agentes

Leia [README.md](README.md) para conhecer o objetivo, o escopo e o estado atual deste repositório.

## Agent skills

### Issue tracker

Especificações e tickets são GitHub Issues deste repositório, acompanhadas no projeto **Migração do portal de ajuda**. Antes de consultar, publicar ou organizar trabalho, leia [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md).

### Triage labels

Use os cinco papéis padrão de triagem. Antes de classificar ou publicar uma issue, consulte [docs/agents/triage-labels.md](docs/agents/triage-labels.md).

### Domain docs

Use um único contexto de domínio: `CONTEXT.md` na raiz e `docs/adr/`. Antes de explorar o código ou propor decisões, siga [docs/agents/domain.md](docs/agents/domain.md).
